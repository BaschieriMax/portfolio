# Redirect da baschierimax.github.io

Il QR code nel CV punta a `https://baschierimax.github.io`. Il portfolio ora è su Netlify
(`https://massimobaschieriportfolio.netlify.app`, vedi D-008): questi file vanno pubblicati
nel repo **`BaschieriMax.github.io`** e servono solo a reindirizzare.

- `index.html` gestisce la root; `404.html` è identico e copre qualunque altro percorso.
- Su GitHub: **Settings → Pages → Source: Deploy from a branch**, branch `main`, cartella `/ (root)`.

Questa cartella non fa parte della build del portfolio.
